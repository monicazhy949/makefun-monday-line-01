A one-line, one-star review of my Monday: an alarm that snoozed itself, 47 unread emails before coffee, and a 9 a.m. meeting that introduced me to my own team. The whole entry is a single sentence, so it reads the same on screen and in the saved file.

## Run it

```sh
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
